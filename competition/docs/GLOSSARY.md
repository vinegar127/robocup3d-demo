# 术语表

| 术语 | 含义 |
|---|---|
| MuJoCo | 计算机器人关节、重力、接触和球运动的物理引擎 |
| RCSSServerMJ | 使用 MuJoCo 的足球比赛服务器，提供感知、动作协议和裁判 |
| Agent | 一名球员的程序；本项目每名球员独立进程 |
| Perception | 服务器发给某一名球员的感知数据 |
| World model | 球员根据自身感知和合法队内消息维护的场上认知 |
| Quaternion | 四元数，本项目按 `(w,x,y,z)` 表示三维朝向 |
| PD control | 根据目标位置和速度误差施加关节作用，kp/kd 是控制增益 |
| ONNX | 用于运行已训练神经网络的模型格式；此处使用 CPU 推理 |
| Policy | 根据传感器状态及目标输出动作的策略 |
| Beam | 规则允许时的开球摆位指令，不能代替运动战行走 |
| Active player | 当前主要负责接近和处理球的球员 |
| Pass release | 出球后停止追抢，给接球者处理球的空间 |
| Staleness | 一条观测已经多久没有更新，是判断其可信度的依据之一 |
| Fixture | 训练测试的初始场景，不是比赛球员可使用的额外权限 |
| Ground truth | 训练端的真实物理状态，本项目只用于评估 |
